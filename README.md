# Exercice - jeu des phrases

Le but de l'app est de générer des phrases aléatoires.

## V1
L'app génère une phrase aléatoire à chaque refresh.

## V2
On peut appuyer sur un bouton pour générer une nouvelle phrase qui s'ajoutera à la liste.
On gère aussi pour qu'il n'y ait pas de doublon.

## V3
Persistence des données. Lorsqu'on refresh / revient sur la page, on récup la liste générée au préalable + boutton reset pour la remettre à 0.
